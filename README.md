## Overview

Zip splits the signal into up to four bands and applies independent transient enhancement or reduction per band, enabling surgical transient shaping that works on full mixes without introducing pumping.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Unfiltered Audio Zip** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multiband Splits** | Up to four configurable crossover points for per-band transient work |
| **Attack Control** | Amplify or attenuate transient onset per band without level change |
| **Sustain Control** | Extend or shorten the body of each frequency band independently |
| **Oversampling** | 4x oversampling option minimizes aliasing during heavy transient boost |
